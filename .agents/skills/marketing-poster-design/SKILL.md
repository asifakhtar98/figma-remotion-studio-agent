# Creative Non-Slop Marketing Poster Design Skill

This skill guides the creation of high-fidelity, bespoke marketing posters, launch graphics, feature showcases, and promotional visuals built as Remotion still compositions (`durationInFrames={1}`).

---

## 1. Strictly Forbidden "AI Slop" Design Tropes

To ensure every poster looks like it was designed by a world-class brand agency rather than generated by a generic AI template, **NEVER** use the following tropes:

- 🚫 **No Purple-on-Dark Clichés**: Avoid defaulting to dark purple/violet glowing background blobs with violet accent text. Use the project's authentic brand palette or curated high-contrast HSL combinations.
- 🚫 **No Symmetrical Boring Center-Stacks**: Avoid stacking every element dead-center with equal padding and uniform sizing. Break the grid with intentional asymmetry, varied scales, and overlapping z-index layers.
- 🚫 **No Generic Equal-Weight Grids**: Never lay out 3 identical centered cards with random icons and one-word labels. Vary card sizes, orientations, and highlight primary vs secondary features clearly.
- 🚫 **No Meaningless Buzzwords**: Avoid generic fluff like "Empower your experience" or "Next-gen solutions". Use specific product metrics, real features, and compelling value props.
- 🚫 **No Fake/Hand-Coded Graphics**: Never attempt to manually draw complex logos or illustrations using canvas/SVG path hacks. Use real brand assets from `src/assets/` or clean, modern typography.

---

## 2. Distinct Creative Aesthetic Directions

Select an art direction tailored to the product personality:

### Direction A — Dark Cyber-Glass (Modern Tech & Social Platforms)
- **Palette**: Obsidian/Slate background (`#090d16`), vivid cyan/sky accent highlights (`#29B6F6`), ambient directional lighting.
- **Mockups**: 3D angled smartphone frame with realistic live app UI, glassmorphic backdrop-blur (`backdrop-blur-xl`), and crisp metallic border rims (`border-slate-700/80`).
- **Floating Cards**: Asymmetrically tilted pill cards (`rotate-[-3deg]`, `rotate-[4deg]`) overlapping the device frame.

### Direction B — Neo-Brutalist Pop (High-Energy & Creator Apps)
- **Palette**: High-contrast solid yellow/cyan/pink blocks against dark or stark-white canvas.
- **Styling**: Hard-edged solid 3px/4px borders (`border-black`), hard offset block shadows (`shadow-[8px_8px_0px_#000000]`), bold chunky badges.
- **Typography**: Ultra-heavy display sans (`font-black tracking-tighter`) paired with monospace accents.

### Direction C — Studio Minimalist (Apple-Grade Premium SaaS & Utilities)
- **Palette**: Soft monochrome background with single brand accent hue.
- **Styling**: Generous whitespace, subtle ambient studio drop shadows (`shadow-2xl shadow-black/40`), razor-sharp typography scale.
- **Mockups**: Clean, floating bezel-less screen view with precise spacing and subtle ambient reflections.

## 3. Poster Formats & Aspect Ratios

| Format / Aspect Ratio | Resolution (`width` × `height`) | Target Medium |
|---|---|---|
| **Full HD Vertical Poster** | `1080 × 1920` (9:16) | Mobile social stories (Instagram, TikTok), digital signage, mobile sharing |
| **Landscape Banner Poster** | `1920 × 1080` (16:9) | Desktop web headers, presentation slides, YouTube banners, digital billboards |
| **Square Social Poster** | `1080 × 1080` (1:1) | Instagram/Twitter feed posts, LinkedIn updates, product cards |

## 4. Visual Hierarchy & Layering (5-Zone Framework)

```
┌──────────────────────────────────────────────────────────┐
│ 1. Eyebrow Badge (e.g. 🚀 OFFICIAL LAUNCH • NOW AVAILABLE)│
│ 2. Brand Logo + Name                                     │
│ 3. Asymmetric Headline & Slogan                          │
├──────────────────────────────────────────────────────────┤
│ 4. Central Focal Point (Layered Depth):                   │
│    - Off-center / Angled 3D Device Frame with real UI     │
│    - Asymmetric Floating Feature Pills (Overlapping edge) │
│    - Contextual Metrics Badge (e.g., "14.2k Live")        │
├──────────────────────────────────────────────────────────┤
│ 5. Bottom Actionable Footer:                             │
│    - Store Badges (App Store & Google Play SVG icons)    │
│    - QR Code Installation Frame                          │
│    - Web Domain Link (e.g., www.domain.com)              │
└──────────────────────────────────────────────────────────┘
```

## 5. Workflow & Implementation Steps

### Step 1 — Clarify Requirements (Q&A)
Ask the user through `ask_question`:
1. **Aspect Ratio**: Vertical (`1080x1920`), Landscape (`1920x1080`), or Square (`1080x1080`).
2. **Creative Art Direction**: Cyber-Glass (Default), Neo-Brutalist, or Studio Minimalist.
3. **Headline & Core Value Prop**.
4. **Download Links / QR Code Details**.

### Step 2 — Asset & Token Grounding
- Inspect existing project screens to re-use brand colors, typography, logos, and real screen mockups.
- Import real logo/product asset images from `src/projects/<project>/src/assets/`.

### Step 3 — Build Component (`src/projects/<project>/src/screens/<PosterNameScreen>.tsx`)
- Use `AbsoluteFill` from `remotion`.
- Implement chosen creative aesthetic with asymmetric floating cards and layered ambient lighting.
- Render realistic app screen content inside device frame (using `<Img>` for photo assets, live chat badges, real metrics).

### Step 4 — Register & Sync
- Register `<Composition>` in `src/Root.tsx` with `durationInFrames={1}`.
- Run `npm run sync:viewer` to regenerate composition registry.
- Render still frame via `npx remotion still <composition-id> out/poster.png`.
- Run `npx tsc --noEmit` and commit changes.

## 6. CSS Utilities & Code Snippets

- **Glassmorphic Card with Ambient Rim**:
  ```tsx
  <div className="flex items-center gap-3.5 rounded-2xl border border-sky-400/30 bg-slate-900/90 px-6 py-4 backdrop-blur-xl shadow-2xl shadow-sky-500/20">
  ```
- **Neo-Brutalist Hard Shadow Card**:
  ```tsx
  <div className="flex items-center gap-4 rounded-2xl border-3 border-black bg-yellow-300 p-5 shadow-[6px_6px_0px_#000000] text-black">
  ```
- **Ambient Lighting Halo**:
  ```tsx
  <div className="absolute -top-[200px] left-1/2 -translate-x-1/2 rounded-full opacity-40 blur-[140px] bg-sky-500 w-[900px] h-[700px]" />
  ```
